# GuildToGlory Online

GuildToGlory Online is a 2D Guild MMORPG project built with PixiJS, Colyseus, Node.js, and TypeScript.

## Technology Stack

- **PixiJS** for 2D rendering
- **Colyseus** for multiplayer game-server functionality
- **Node.js** for the server runtime
- **TypeScript** for application development

## Project Status

This repository is at an initial documentation stage. Dependencies have not been installed, and no game systems have been implemented yet.
